# Notes variant — Leadership / Exec

Use this body order (instead of the standard Phase-3 template) when Step 0 selected the
**leadership** notes variant — exec/strategy conversations where leaders decide *how to
run the org*, not execute tasks. Everything else in the skill (frontmatter, `## Source &
Metadata`, attendee enrichment, dual-brain, output variant, etc.) is unchanged; only the
body sections differ.

Same rules as the standard format: **optional sections are omitted entirely when empty**,
and `Action Items` still scans for promises the user made to others (tag each `(promise)`).

## Body order

```markdown
# {Meeting Title} — {Date}

**Attendees:** {links + emails}
**Date:** {…} · **Format:** {…} · {~duration}

## Source & Metadata
{the standard metadata block — see Phase 3}

## Executive Summary
{tight skim: what it was, what changed/decided}

## Decisions Made
{concrete decisions + the WHY/context behind each. The core output of an exec convo.}

## Open Decisions / To Decide
{decisions raised but not resolved — the parking lot. Leadership's most-dropped item;
never omit a real open decision. Note who needs to decide / by when if said.}

## Strategic Context & Goals
{the high-level direction / objective the conversation served — the "why behind the why".}

## Operating Changes
{changes to HOW the team/org runs — process, cadence, structure, roles, tooling.}

## Alignments & Tensions
{where the leaders aligned, and where they disagreed/debated and how it resolved (or
didn't). Exec conversations are largely about resolving tension — capture both sides.}

## Action Items
{concrete owner-tagged tasks; include `(promise)`-tagged commitments the user made.}

## Next Steps
{directional moves that matter but aren't yet atomic tasks.}

## Risks / Watch-outs / Open Questions
{risks raised, things to monitor, unresolved questions.}

## People & Org
{delegation, who-owns-what, hiring/personnel/team calls.}

## Meeting Historical Breakdown
{chronological segments with bullets — same as standard.}

<!-- timeline -->

## Timeline
- {YYYY-MM-DD} — {one-line dated summary}

## See Also
- {attendees, companies, programs; companion brain page if dual; raw transcript}
```

## Notes
- Prioritize **Decisions Made** and **Open Decisions** — they're the reason this format
  exists. If the conversation was all process (like an OKR/cadence sync), **Operating
  Changes** carries the weight.
- Keep `Strategic Context & Goals` tight — it frames the decisions, it isn't a strategy essay.
