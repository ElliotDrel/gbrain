# Execution split — do-now vs. carry-forward (all brains)

Run this whenever a meeting produced **Action Items**, regardless of brain. It's the
shared execution step (it used to live only in the personal variant). It runs after the
notes are ingested, alongside the routed follow-up — they're independent.

## What it does
Take the page's **Action Items** (the ones already captured, including `(promise)`-tagged
commitments) and split each into one of two buckets:

- **Do now** — the agent can actually do it now, or it's a genuine <5-minute action →
  do it (or tee up the artifact, e.g. draft the email/doc) immediately, then mark it done.
- **Track** — a real bounded action (concrete verb, bounded scope, an actual next move) that
  isn't doable this second → carry it forward in the final delivery.

Only concrete next moves count — a vague target ("get to 15 interviews") doesn't qualify.

## Whose items
- Only carry forward **the user's own** action items. Other people's items stay in the
  follow-up / team recap for them — don't surface teammates' items as the user's.

## Flow (split → do now → carry forward)
1. **Split** each action item into **Do now** vs **Track** (each Track item with a concrete
   next move, and a rough due date — default to the next meeting when none was stated).
2. **Execute the Do now items** immediately, or tee up the artifact (draft the email/doc),
   then mark them done.
3. **Surface the split** in the final delivery: what you did now, plus the user's own Track
   items carried forward for them to review there.

## Notes
- This is separate from the follow-up method — a meeting always gets a follow-up; it only
  gets an execution split if it has action items.
- If there are no action items, skip this step entirely.
