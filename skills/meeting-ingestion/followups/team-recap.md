# Follow-up method — Team recap (buildpurdue team meeting only)

Use this **only** for the buildpurdue weekly **team meeting** — a recap posted to the
whole team (Slack). Every other meeting (including buildpurdue 1-on-1s) uses
`follow-up-message.md`. Draft this after the meeting page is ingested and enriched
(router `SKILL.md` Phase 8). Output only the recap message, ready to paste — no
meta-commentary. Leave it **ready to post and do not auto-send it**; the user posts it
to the team from the final delivery (Phase 10).

## Goal & tone
A quick, actionable summary — what was covered + clear action items with due dates.
Brief, action-oriented, casual-but-professional, outcomes over discussion detail,
scannable.

## Content requirements
- **What we covered (3–5 bullets):** the most important info — decisions made,
  progress updates, key alignments/takeaways. One line each where possible.
- **Action items:** extract every task/commitment/next step. Include specific due
  dates/times when stated; if none was given, default the deadline to the **next
  meeting**. Use imperative verbs (Find, Send, Update, Finalize). **Bold** any
  overarching goal or important reminder. Group items by person. Include recurring
  reminders/processes (e.g. "if you can't attend, have someone present your
  section"; "blocked? call it out in #announcements"; who to keep on calendar invites).
- Do **not** include exact citations.

## Format (exact)

```
# Quick recap from the [M/D] team meeting:

__**What we covered:**__
- [bullet]
- [bullet]
- [bullet]

__**Action items due [next meeting, e.g. Sat]:**__
**[bold overarching goal / context, if applicable]**
- [Person]: [imperative action item(s)]
- [Person]: [imperative action item(s)]
- **[bold important reminder]**

**Next meeting:** Next [day] [time] (weekly).
```

## Notes
- Header uses the meeting **date** (e.g. `5/30`), not a meeting number.
- buildpurdue cadence is **Saturday 4pm, weekly** — phrase the next-meeting line as
  `Next Saturday 4pm (weekly)` unless a different time was set that day.
- **No** "Meeting Notes" line, **no** "missed it" section, **no** "let me know if you
  have any questions" closing — end on the next-meeting line.
- This recap is posted to the whole team (Slack), so use markdown the surface
  supports (`#`, `-`, `**bold**`, `__underline__`).
- Task/execution handling (do-now vs task manager) is the shared `execution-split.md`
  step, run separately — the recap itself just lists the action items for the team.
